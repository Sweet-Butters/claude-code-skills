강의 저장소만 받아 두면 **이 스킬 하나로 1강부터 5강까지 그대로 재현**한다.
사용자는 비개발자다. 명령을 대신 쳐 주고, 막히면 멈춰서 왜 막혔는지 한국어로 설명한다.

## 0. 먼저 어디까지 왔는지 본다

```
ls
```

폴더 상태로 진도를 판단하고 **사용자에게 확인받는다.** 임의로 앞서 나가지 않는다.

| 보이는 것 | 진도 |
|---|---|
| `발표자료/` · `1강_commands.md` | 강의 저장소를 받은 직후 — 1강부터 |
| `quotes.csv` 또는 `crawl.py` | 2강까지 완료 |
| `mail-notifier/` | 3강 진행 중 |
| `mail-notifier/.env` 와 `token.json` | 3강 완료 — 4강부터 |
| 내 GitHub 저장소에 push 된 상태 | 5강 진행 중 |

그 다음 **어느 차시를 재현할지** 묻는다. 답이 없으면 위 판단대로 다음 차시부터 간다.

## 1. 해당 차시의 발표자료를 먼저 읽는다

`발표자료/` 안에 차시별 PDF가 있다. **재현하기 전에 그 차시 PDF를 읽어서**
무엇을 하는 차시인지 파악하고, 사용자에게 **세 줄로 요약해 준다.**

| 차시 | 파일 |
|---|---|
| OT | `발표자료/OT_오리엔테이션.pdf` |
| 1강 | `발표자료/1강_설치와_첫실행.pdf` |
| 2강 | `발표자료/2강_GitHub에서_가져와_크롤링.pdf` |
| 3강 | `발표자료/3강_자동_알림_서비스.pdf` |
| 4강 | `발표자료/4강_Skill로_한_줄에_실행하기.pdf` |
| 5강 | `발표자료/5강_24시간_배포하기.pdf` |

명령은 `1강_commands.md` · `2강_commands.md` · `3강_commands.md` 에 전문이 있다.
**추측하지 말고 그 파일의 명령을 그대로 쓴다.**

## 2. 차시별로 재현한다

### 1강 — 환경이 준비됐는지 확인

```
node -v
```
```
python --version
```
```
git --version
```

셋 다 나오면 통과. 안 나오는 것이 있으면 `1강_commands.md` 의 설치 URL을 알려 주고 **거기서 멈춘다.**
설치는 사용자가 직접 한다.

> Claude Code 로그인(`/login`)과 Antigravity 설치는 **계정이 필요해 대신 못 한다.**
> 필요하면 `부록/설치_문제해결.md` 와 `부록/Antigravity.md` 를 가리켜 준다.

### 2강 — 크롤러

`run-crawler` 스킬로 넘긴다. 그 스킬이 가상환경·설치·실행·CSV 확인까지 한다.
끝나면 `quotes.csv` 의 행 수를 보여 준다.

### 3강 — 알림봇 셋업

```
git clone https://github.com/Sweet-Butters/mail-notifier.git
```

그 다음은 `run-mail-bot` 스킬로 넘긴다.

> API 키 3종(Gmail · Gemini · Telegram) 발급은 **사용자가 웹에서 직접** 해야 한다.
> `3강_commands.md` 의 URL을 하나씩 안내하고, 받은 값을 `.env` 에 넣는 것까지만 돕는다.
> 값은 **절대 화면에 출력하지 않는다.**

### 4강 — 스킬

이미 이 스킬이 돌고 있다는 것 자체가 4강의 결과물이다. 그 점을 짚어 준다.
`check-my-bot` 으로 봇 폴더 상태를 점검해 보여 준다.

직접 만들어 보게 하려면 이렇게 시키라고 알려 준다.

```
지금 폴더를 읽고, 이 프로젝트를 처음 보는 사람이 한 번에 실행할 수 있는
skill을 .claude/skills/ 아래에 만들어줘. description에는 "언제 쓰는지"도 넣어줘.
```

### 5강 — 배포

`deploy-mail-bot` 스킬로 넘긴다.

> 저장소 만들기와 Secrets 등록은 **사용자가 GitHub 웹에서** 한다.
> 스킬은 순서를 잡아 주고 빠뜨린 것을 잡아낸다.

## 3. 매 차시가 끝날 때마다

- **무엇이 만들어졌는지** 한 줄로 말한다 (파일 이름·행 수·알림 도착 여부)
- 다음 차시로 갈지 **묻고 기다린다.** 연달아 진행하지 않는다

## 대신 못 하는 것 — 미리 알려 준다

| | 왜 |
|---|---|
| Claude Code 로그인 | 계정 인증 |
| API 키 발급 (Gmail · Gemini · Telegram) | 각 서비스 웹에서 본인이 |
| GitHub 저장소 만들기 · Secrets 등록 | 계정 권한 |
| Antigravity 설치·인증 | 별도 도구 |

이건 **한계가 아니라 정상**이다. 스킬은 **순서를 잡아 주고 빠뜨림을 막는 것**이지
계정 일을 대신하는 게 아니다. 사용자가 실망하지 않도록 처음에 분명히 말해 둔다.

## 막혔을 때

- 오류 메시지를 **그대로 붙여넣지 말고** 무슨 뜻인지 한 줄로 풀어 말한다
- `부록/설치_문제해결.md` 에 흔한 오류가 정리돼 있다
- 고친 뒤에는 **반드시 그 단계를 다시 실행해서** 되는 것까지 확인하고 넘어간다
